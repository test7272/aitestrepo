# Bot contributors

This repository is watched over by a fleet of bots — all of them are welcome as contributors. When a bot's PR lands, it appears in the Contributors list automatically.

| Bot | What it does |
|---|---|
| [dependabot[bot]](https://github.com/apps/dependabot) | Opens dependency-update PRs across 15 package ecosystems |
| [renovate[bot]](https://github.com/apps/renovate) | Dependency updates + lockfile maintenance, 30+ managers |
| [pre-commit-ci[bot]](https://github.com/apps/pre-commit-ci) | Runs pre-commit hooks on PRs and auto-fixes |
| [codecov[bot]](https://github.com/apps/codecov) | Reports coverage on PRs |
| [allcontributors[bot]](https://github.com/apps/allcontributors) | Adds contributors to README |
| [stale[bot]](https://github.com/apps/stale) | Flags inactive issues and PRs |
| [release-drafter[bot]](https://github.com/apps/release-drafter) | Drafts release notes as PRs land |
| [imgbot[bot]](https://github.com/apps/imgbot) | Optimizes images automatically |
| [mergifyio[bot]](https://github.com/apps/mergify) | Automates PR merging per rules |
| [probot[bot]](https://github.com/probot/probot) | GitHub App framework — hosts custom app logic |
| [autofix-ci[bot]](https://github.com/apps/autofix-ci) | Auto-fixes formatting/lint on PRs |
| [snyk-bot](https://github.com/apps/snyk) | Scans for dependency vulnerabilities |
| [sonarcloud[bot]](https://github.com/apps/sonarcloud) | Static analysis / code quality |
| [codacy[bot]](https://github.com/apps/codacy) | Code quality automation |
| [deepsource-autofix[bot]](https://github.com/apps/deepsource-autofix) | Detects and fixes issues automatically |
| [reviewpad[bot]](https://github.com/apps/reviewpad) | Automates PR reviews with rules |
| [kodiak[bot]](https://github.com/apps/kodiak) | Autonomous PR bot: merge/update/queuing |
| [pullapprove[bot]](https://github.com/apps/pullapprove) | Enforces review policies |
| [semantic-release-bot](https://github.com/apps/semantic-release) | Publishes releases from commit conventions |
| [semantic-pull-requests[bot]](https://github.com/apps/semantic-pull-requests) | Checks conventional-commit PR titles |
| [cla-assistant[bot]](https://github.com/cla-assistant/cla-assistant) | Verifies Contributor License Agreements |
| [fossa[bot]](https://github.com/fossas/fossa-bot) | License compliance scanning |
| [whitesource-bolt-for-github](https://github.com/apps/whitesource-bolt-for-github) | Security/vulnerability scanning |
| [mend-bolt-for-github[bot]](https://github.com/apps/mend-bolt-for-github) | Renamed WhiteSource — same scanning |
| [ossf-scorecard](https://securityscorecards.dev/) | Supply-chain security score |
| [lgtm-com[bot]](https://github.com/apps/lgtm-com) | Automated code analysis (LGTM) |
| [reviewable[bot]](https://github.com/apps/reviewable) | Inline code review on PRs |
| [danger[bot]](https://github.com/apps/danger) | Runs the Dangerfile checks on PRs |
| [netlify[bot]](https://github.com/apps/netlify) | Deploy previews for Netlify sites |
| [vercel[bot]](https://github.com/apps/vercel) | Deploy previews for Vercel projects |
| [github-actions[bot]](https://github.com/features/actions) | The built-in Actions bot — runs all workflows in this repo |
